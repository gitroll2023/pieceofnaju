# 나주한조각 — 추천 탭 & 여행 코스 시스템 기획안 (v4)

## 1. 한 줄 방향 (무엇을 만드는가)

발견·내조각 사이에 **추천 탭**을 신설해, ① 운영자가 검수한 **실데이터 시드 코스**와 사용자 공유 코스를 한 피드에 보여주고, ② 경비·기간·인원·아이·술·관광객/시민 6조건으로 **맞춤 루트**를 짜주며, ③ 만든/받은 코스를 내조각의 **코스 탭**에 "코스 모양 조각"으로 저장해 **따라가기(가기 전 비활성 → 다녀오면 활성)** 하는 시스템. 핵심 원칙: 모바일 컴팩트, 비회원 가능, 서버리스, 개인정보 최소, **실데이터만(더미 금지)**, 런타임 LLM 남발 금지.

> 코드 사실 메모: `src/lib/data/types.ts`의 `Category`는 실제로 `food|cafe|spot` 3종이다(마케팅의 '5조각'은 spot을 관광/레저/체험으로 세분한 표시 레이어). 코스 stop의 `kind`는 이 3종 코드 타입을 그대로 쓰고, 5조각 라벨은 UI 배지에서만 파생한다 — **타입 이원화 금지**.

## 2. 정보구조: 3탭 + 추천 탭 화면

### 탭바 (`src/components/shell/TabBar.tsx` — 배열 1줄 추가만)
현재 `TABS`는 2개, `<ul>`이 이미 `repeat(${TABS.length}, 1fr)`로 동적이고 active 판정도 `pathname.startsWith(href)`라 **코드 변경은 배열에 한 줄 + import 아이콘 하나**뿐.
```tsx
import { Map, Sparkles, Puzzle } from "lucide-react";
const TABS = [
  { href: "/",          label: "발견",   icon: Map },
  { href: "/recommend", label: "추천",   icon: Sparkles },  // 중앙 신설
  { href: "/pieces",    label: "내조각", icon: Puzzle },
] as const;
```
중앙 배치 = 엄지 도달 + "결정 못 했을 때 여기" 심리. `/recommend/[id]` 상세에서도 `startsWith`로 탭 하이라이트 유지.

### 라우트 트리
```
/recommend              추천 피드(조건 CTA + 빠른조건 칩 + 코스 카드 피드)
/recommend/build        조건 입력(90vh 바텀시트) → 결과로 push
/recommend/[id]         코스 상세 = 여행 루트 타임라인
/recommend/r/[token]    공유링크 수신(읽기전용 미리보기 → "내 코스로 저장")
/pieces?tab=course      내조각 > 코스 탭(쿼리 세그먼트)
```

## 3. 조건 맞춤 모델 (입력 UX + 매칭)

### 입력 UX (6조건, 컴포넌트 차등 — 90vh 바텀시트, `animate-rise` 재사용)
| 조건 | 컴포넌트 | 옵션·이유 |
|---|---|---|
| 일정 | 세그먼트(택1) | `당일 / 1박2일 / 2박3일` — 루트 길이 결정 1차 변수라 먼저 묻기 |
| 경비 | 3단 세그먼트 + 미세 슬라이더 | `₩가볍게/₩₩적당히/₩₩₩든든히`(1인 만원대 라벨 병기). 톤 우선, 선택 시 1인 캡 ±조정 |
| 인원 | 스텝퍼 `[- 2 +]` | 1~8. 좌석·예약 힌트 + 연료/주차 분담 계산 |
| 아이 동반 | 토글 칩 | on → 야간 술집·계단많은 코스 제외, 박물관·호수공원 가중 |
| 술 | 토글 칩 | on → 양조장·홍어삼합·포차 허용, off → 카페·디저트로 치환 |
| 방문 성격 | 세그먼트(택1) | `관광객 / 나주시민` — 시민이면 초유명집(곰탕거리)↓, 숨은 동네·신규 가맹점↑ |

UX 규칙: **전부 선택 강제 금지**(기본값 = 당일·적당히·2인·아이X·술X·관광객), "스킵하고 추천받기" 상시 노출. 조건은 URL 쿼리로 직렬화(`/recommend/build?d=day&b=2&n=2&kid=0&al=0&v=tour`) → 공유·새로고침·뒤로가기 보존, 서버리스 상태저장 불필요. 결과 상단에 **선택 조건 요약 칩 줄**, 칩 탭 시 그 조건만 재수정(전체 재입력 방지).

### 매칭 알고리즘 (시드 스코어링 → 부족 시 조합)
입력 정규화 후 **1단계 시드 스코어링**:
```
score(seed, c):
  if seed.days != c.days:            -40
  if c.withKids && !seed.kidFriendly: -50
  if c.drinking != seed.hasAlcohol:  -15
  budget: seed.budgetMax<=c.budget +30 / 부분초과 +10 / 초과 -25
  if c.area in seed.areas:           +20
  visitorType 일치도:                +15
  태그 교집합:                       +8 * |seed.tags ∩ desiredTags(c)|
candidates[0].score >= THRESHOLD → adaptSeed(인원/날짜로 경비·식수만 재계산)
```
THRESHOLD 미달이면 **2단계 조합 생성**(아래 5절). 하드 필터는 "제외" 대신 큰 페널티로 — 결과가 비는 것을 막기 위함.

## 4. 코스 데이터 (시드·스키마·공유)

### 시드 코스 7종 (모든 stop은 우리 실데이터 실재 장소명, 미존재는 `GAP:` 표시)
1. **`seed_first_halfday`** 처음 온 사람 핵심 반나절 — 금성관→나주목사내아 금학헌(GAP)→서성문→나주향교→나주곰탕 하얀집→국립나주박물관. 관광객·아이X·술X·반나절·원도심·~2.5만.
2. **`seed_3mi_food`** 나주 3미(곰탕·홍어·장어) — 하얀집→금성관 산책→빛가람 감성카페(GAP 큐레이션)→빛가람호수공원→영산포 홍어거리(GAP)→아트스페이스영산포. 술有·하루·~5만.
3. **`seed_family_kids`** 아이와 실내+야외 — 국립나주박물관(어린이박물관)→나주덕산리고분군→하얀집→빛가람호수공원(분수·모노레일)→빛가람전망대모노레일→배 디저트카페(GAP). 아이有·술X·~3만/성인.
4. **`seed_couple_sunset`** 호수 노을·야경 — 달가림양조장→빛가람 베이커리카페(GAP)→빛가람호수공원(노을·5월 장미)→빛가람전망대카페비하인드. 술 약간·반나절~하루·~4만.
5. **`seed_yeongsanpo_retro`** 영산포 근대 골목+황포돛배(술 테마) — 영산포 등대(`tour_2603506`)→영산강 황포돛배(GAP 체험)→한국천연염색박물관→영산포 홍어거리(GAP)→아트스페이스영산포→영산포역사갤러리(GAP). 술有·하루·~4.5만.
6. **`seed_history_deep`** 역사·향토 답사 — 금성관→나주향교→남고문→하얀집→광주학생독립운동진원지나주역사→국립나주박물관→나주덕산리고분군. 하루·~2.5만.
7. **`seed_nature_2day`** 1박2일 자연·힐링(시민/재방문) — Day1 나주수목원→불회사→도래전통한옥마을(숙박)→카페정원 / Day2 나주호 우주드림→빛가람호수공원→영산강정원(GAP 일부). ~12만(숙박 포함).

출처: [나주시 1박2일 코스](https://www.naju.go.kr/tour/recommend/course/days2), [구석구석 뚜벅이·영산포 근대·힐링 코스], [황포돛배 체험](https://www.naju.go.kr/tour/recommend/experience/sailboat), [영산포 홍어거리].

### 공유·받기 데이터 흐름
```
[시드] seed-courses.json → 조건필터 → "담기" → 비회원 localStorage / 회원 POST /api/courses(kind=course,seedId)
                                              → 내조각>코스탭 → 따라가기(stop todo→done)
[사용자] 코스 만들기 → POST courses(is_public=false) → 공개전환(is_public=true) + posts 공유글
                    → 추천 피드 노출 → 타인 "받기"(courses 복제, user_id=받는사람, origin=received, done 전부 false)
                    → 신고 feedback(target=course_id) → /pieceadmin 검수 → is_public=false
[비회원→회원] localStorage 코스/진행 → 가입 시 1회 bulk 업서트, id 기준 머지(done OR)
```

## 5. 코스 생성·동선·경비

### 권고: 시드+규칙 기본, LLM은 런타임 기본경로에서 제외
| | 런타임 LLM 매요청 | **시드+규칙(권고)** | 온디맨드 LLM 다듬기(보조) |
|---|---|---|---|
| 비용 | $0.01~0.05/req | $0 정적+JS | 명시 트리거 시에만 |
| 지연 | 2~8초 | 수십 ms | 2~5초(사용자 수용) |
| 환각 | 폐업·잘못된 좌표·영업시간 오기 | 검증 실데이터만 | 후처리 검증 필수 |
| 서버리스 | 콜드스타트+타임아웃 누적 | 함수 내 순수연산 안전 | 단발 허용 |

이 서비스의 출력은 "실제 영업 가게+정확 좌표+영업시간"이라 런타임 자유생성은 환각 위험이 구조적. 시드+규칙은 **출력 노드가 항상 검증된 merchants/spots의 부분집합** → 더미 금지 원칙을 구조로 보장. **Claude 사용 지점은 둘뿐**: (1) 큐레이션 배치 — 시드 `why`/`vibe` 카피를 토스풍+손맛으로 작성 후 운영자 검수 커밋(런타임 0원), (2) 온디맨드 "다듬기" — 사용자가 "술 코스로 바꿔줘" 누를 때만 1회, **입력에 후보 노드 목록 주고 출력은 그 id enum으로만 재배열** 강제(환각 차단) + 호출 캡.

### 조합 생성 (시드 부족 시) + 동선
```
pool = buildPool(c)   # food=merchants(food,non-franchise) / drink=cafe∪양조장 / spots=계절필터
                      # withKids→drop bars,prefer 체험·공원 / !drinking→drop 주점 / area→가중(배제X)
                      # resident→demote 곰탕거리, promote 로컬·계절
anchor=권역 상징(원도심=금성관); greedy nearest-neighbor로 끼니(점심/저녁 윈도우 고정)+관광 슬롯 채움
route = twoOptPerDay(route)   # 노드 8개 이하라 비용 무시
```
**이동시간 근사**(외부 API 0, `geo.ts` `distanceKm` 재사용): 하버사인 ×1.3 우회보정 → `<1.2km` 도보 4km/h, 그 외 차량 26km/h + 주차·하차 6분. 실거리는 `directionsUrl`로 사용자 위임.
**체류시간**: food 60 / cafe 40 / 문화재 40 / 박물관 60 / 체험 90 / 레저 120 / 양조장 50 / 산책 30분. 아이동반 ×1.2, relaxed ×1.15.
**경비**(가격 필드 없음 → 운영자 검수 상수 단가표): 곰탕·한식 9~13천 / 카페 5~7천 / 체험 15~25천 / 문화재 다수 무료. 연료·주차만 인원수로 분담. **항상 범위로 표기**("1인 약 ₩{min}~{max}, 식사·입장 기준, 주차·기타 제외"), 단정 금지. 초과 시 고가 노드를 무료 문화재·산책으로 치환 후 재계산.

### 표기 UX + 시간표 반영
- **데이터 있을 때**: stop 카드 칩 `영업 11:00–21:00·브레이크 15:00–17:00·휴무 월`. 추천 `arriveLabel`이 브레이크/휴무와 겹치면 **경고 배지 + 대체 시간 제안**. 시간표 생성기가 이 필드로 충돌 회피(점심 곰탕 13:00 고정 → 15~17 브레이크 자연 회피, 밀리면 앞당기거나 같은 카테고리 최근접 swap). `updatedAt` 90일 초과 → "정보가 오래됐을 수 있어요".
- **데이터 없을 때(대다수 KB가게)**: 단정 금지. "영업시간 정보 미확인" + 일반 안내 "점심·저녁 사이 브레이크가 있을 수 있어요, 방문 전 확인을 권해요" + **카카오맵 상세 딥링크 버튼**(`geo.ts` `directionsUrl` 옆에 `placeUrl` 추가)으로 위임. 미등록이면 "사장님이세요? 영업시간 등록하기" CTA → 데이터 자가증식.
- **신뢰 우선순위**: `kakao` > `public` > `unknown`. unknown은 제약으로 쓰지 말고 안내 배지로만.

## 7. 코스 조각 & 내조각 코스 탭

### 코스 조각 모양 차별화 — "이어진 띠(리본)"
일반 조각 = 단일 퍼즐(`.piece-thumb` SVG 마스크, `globals.css`). 코스 조각 = **여러 퍼즐 탭이 가로로 맞물린 띠** → "여러 조각이 하나의 길로 이어졌다"가 형태로 즉시 읽힘. `globals.css`에 `.course-thumb` 추가(동일 기법, viewBox 가로형 `160×72`, `aspect-ratio:160/72`).
- **권장 폴백**(SVG path 디버깅 리스크 회피): 마스크는 단순 가로 라운드 사각으로 두고, 띠 위에 stop 수만큼 작은 퍼즐 도트를 `─◇─◇─◇─`로 얹어 "이어짐" 표현.
- 색: 단일 조각=카테고리 색 1개. 코스 조각=stop 카테고리 색을 좌→우 linear-gradient("여정의 색 변화"). 완주 시 채도 100% + ✦완주 도장.
- 그리드: 일반 `grid-cols-3`, 코스 조각 `col-span-2`(띠는 가로로 길게). 코스 탭에선 1열 풀폭.

### 내조각 코스 탭 (`/pieces?tab=course`)
헤더 아래 세그먼트 `[ 조각 12 | 코스 3 ]`. 코스 탭 = 리본 썸네일 1열 리스트, 각 카드: 제목 / `3/5 다녀옴` 진행바 / `따라가기` / 출처(시드·내가만듦·받음). 신규 `src/lib/useCourses.ts`(`useStamps` 패턴 복제), 로컬 키 `naju.courses.v1`, Neon `courses` 컬럼과 1:1:
```ts
type SavedCourse = {
  id: string; title: string; kind: "course";
  origin: "seed" | "mine" | "received";
  items: { placeId: string; n: string; c: Category; time?: string;
           lat?: number; lng?: number; t?: string;
           done: boolean; doneAt?: number }[];   // items JSONB
  createdAt: number;
};
```

### 따라가기(체크인 → 활성 조각) — 요구 5번
1. `따라가기` → 코스 상세 타임라인이 체크인 모드로 전환.
2. stop = 순번 배지 + 체크인 버튼. **가기 전 = 비활성(회색·점선·반투명), 다녀오면 = 활성(컬러·실선)**.
3. 체크인 시 동시: ① `items[i].done=true,doneAt=now` ② **일반 조각 자동 적립** `useStamps.toggle({id,n,c,d,at,lat,lng,t})`(코스=여정, 적립 조각=기록, 양쪽 남김) ③ 회원이면 `pieces.visited=true` 동기화.
4. 진행바 `done/전체`, 전부 done이면 리본 완주 도장. stop 사이 `distLabel`/`directionsUrl`로 "다음 1.2km·차5분 [길찾기]". 현재 stop 자동 스크롤 + "지금 여기" 펄스(`.me-dot` 톤).

타임라인: 좌측 세로 라인+노드(번호/시간, done=채움● 미방문=빈○), 우측 장소·이유·경비·이동. 하단 `따라가기 시작 / 카톡 공유 / 내 코스로 저장`.

## 8. 공유 & 카톡

- **내보내기**: 코스 상세 `공유` → `카톡 / 링크복사 / 공개 피드에 올리기`. 공개 = 회원 `is_public=true` → 피드에 `🧩닉네임`. 비회원은 "공개하려면 로그인"(링크복사는 비회원 가능). 카톡 = `pieces`의 `navigator.share` 재사용, URL `/recommend/r/[token]`, 미설치 시 클립보드 폴백(`copied` 토스트).
- **받기**: `/recommend/r/[token]` = 읽기전용 미리보기 + "🧩지우님의 코스" 배지. 하단 `내 코스로 저장` → `useCourses`에 `origin:"received"` 복제(`done` 전부 false). 직후 "따라가기 시작?" → 코스 탭 이동. 회원=`POST /api/courses` 복제, 비회원=로컬만. 복제본은 내 소유.
- **신고**: `feedback(target=course_id)` → `/pieceadmin` 검수 → `is_public=false`.

- 실거리 라우팅 API 런타임 호출 금지(좌표 근사 + `directionsUrl` 위임), 카카오 길찾기는 사용자에게.

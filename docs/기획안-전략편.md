## 1. 한 줄 전략

**나주의 식당·카페 1,830곳 중 42%(766곳)가 빛가람동(혁신도시) 한 권역에 쏠려 있다.** 정렬을 그대로 두면 발견 피드 상단이 "평상시에도 붐비는" 혁신도시로 도배되어, 사장이 살리려는 원도심·영산포·면지역이 더 죽는다. 그래서 우리는 세 가지를 동시에 푼다 — **(1) 상권 불균형**은 권역 가중치·주차 로테이션·행사 역(逆)큐레이션으로 노출을 의도적으로 분산, **(2) "노잼도시" 인식**은 면지역·비수기 발굴 콘텐츠로 반박, **(3) 관광지 발견**은 대표 관광지를 허브로 두고 주변 먹거리·마실거리·인근 명소를 거리기반으로 묶는 허브&스포크로 해결한다. 전부 발견 피드 내부 섹션/필터/정렬과 기존 `place/[id]` 상세 안에서, 새 탭·DB·로그인 없이 정적 연산으로 처리한다.

### 3-2. place/[id] 허브 강화 (새 페이지 아님, 기존 상세 내 섹션)

관광지(spots 55건)=**허브**, 주변 가맹점·인근 관광지=**스포크**. `geo.ts`의 `distanceKm`/`distLabel`/`directionsUrl` 재사용, 데이터 중복 0(런타임 계산).

```ts
// src/lib/hub.ts (신규)
export function spokes(hub, merchants, spots) {
  const near = (m, km) => distanceKm(hub.lat, hub.lng, m.lat, m.lng) <= km;
  return {
    eat:  rankByScore(merchants.filter(m => m.c==='food' && near(m, HUB_WALK_KM))).slice(0,4),  // 도보 1.2km
    cafe: rankByScore(merchants.filter(m => m.c==='cafe' && near(m, HUB_WALK_KM))).slice(0,3),
    nearby: spots.filter(s => s.id!==hub.id)
              .map(s => ({s, km: distanceKm(hub.lat,hub.lng,s.lat,s.lng)}))
              .filter(x => x.km <= HUB_DRIVE_KM).sort((a,b)=>a.km-b.km).slice(0,3),  // 차로 12km
    season: seasonFor(hub),  // flowers.json + spot.season/flower 매칭
  };
}
```

`rankByScore`는 5절 권역 가중치를 **그대로 재사용** → 허브가 혁신도시여도 주변 추천은 로컬 상권 편향 유지. 컴포넌트는 `src/components/place/`에 `PlaceHub`/`SpokeRow`/`SeasonTip` 신규(탭 아님). 각 카드에 `distLabel(km)` + 길찾기 버튼. **스포크 0개면 섹션 자동 숨김**(무해 폴백).

## 5. 권역 균형 큐레이션 (새 탭 0개)

```ts
// src/lib/region.ts (신규)
const REGION_WEIGHT = { yeongsanpo:1.6, myeon:1.4, oldtown:1.3, nampyeong:1.1, innovation:0.55 };
const SPOTLIGHT_POOL = ['yeongsanpo','oldtown','myeon','nampyeong']; // 혁신도시 영구 제외
function spotlightRegion(d=new Date()){ return SPOTLIGHT_POOL[isoWeek(d) % 4]; } // 주차 모듈로 → 매주 자동 변경, 같은 주 결정적
```

**통합 정렬 스코어**:
```
score(item, today):
    base   = qualityScore(item)                         # featured/노포/평점 (6절)
    w      = REGION_WEIGHT[regionOf(item.d)]
    if region == spotlightRegion(today): w *= 1.5       # "이번 주의 한조각"
    if activeEvent && region == activeEvent.region: w *= 0.6   # 행사권역 역가중(4절)
    if isFranchise(item) && !showFranchise: return -Infinity   # 기본 숨김
    jitter = fnvHash(item.id + 'YYYY-MM-DD') * 0.15     # 결정적: 같은 날 안정, 매일 순환
    return base * w + jitter
```

- **추천 슬롯(상단 N개)**: 권역 라운드로빈 — 한 슬롯 채울 때마다 그 권역 가중치 `×0.6` 감쇠로 같은 권역 연속 차단. **혁신도시 추천 슬롯 하드캡 1.**
- **HERO 영역**(날짜 의존, 백엔드 0): 평상시 → "이번 주의 한조각 · {spotlightRegion}", 행사중 → EventCard + "북적임을 피하고 싶다면" 대안 섹션.
- 모든 랜덤은 `id+날짜` FNV 해시 → 같은 날 새로고침해도 순서 동일(껌뻑임 방지), 날짜 바뀌면 자연 순환. **DB·로그인·로그 0.**
- (선택·무해) `localStorage 'naju.regionFatigue'`로 많이 본 권역 소폭 감쇠. 없으면 기본 로직 그대로.

**배지 배치**: `[먹][마실][볼][즐]` 4조각 세그먼트 + `[⭐노포][✨신상]` 칩(눈에 잘 보이게, OR 필터) + 카드 우상단 배지(CategoryBadge 재사용). 노포/신상은 배지+필터 둘 다, 프랜차이즈는 숨김 토글만.

## 8. 단계별 실행안 (v2 Phase 통합)
